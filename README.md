#  KGL – Karibu Groceries LTD Management System

A modern web-based management system for Karibu Groceries LTD, designed to help manage products, sales, and stock efficiently with a clean dashboard interface.

## 📌 Project Overview

KJL is a responsive web application built to support grocery store operations such as:

Managing products and stock

Tracking low-stock items

Viewing top-selling products

Monitoring sales statistics

Providing a clean and user-friendly dashboard

The system is designed with simplicity, performance, and usability in mind.

## Features

 Dashboard with sales statistics

 Product & stock management

Low stock alerts

 Top-selling products table

 Sidebar navigation

Fully responsive design

Login system (UI + JWT authentication)

## 🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling & Layout

JavaScript – Interactivity
**Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Hosting:** Render (backend), GitHub Pages (frontend)

Google Charts – Data visualization

Responsive Design – Mobile friendly
